Telemetry Packets
=================

This appendix lists all the telemetry packets that OBDH can transmit upon telecommand request by the RF links. The fields and length of each type of packet is also presented.

EDC Information
---------------

Telemetry packages from EDC can be seen in :numref:`tab:telemetry-edc`. This data can be requested through the “Get Payload Data” and “Data Request” telecommands, for more information about them see :ref:`sec:telecommands`. PTT packets from the Sistema Brasileiro de Coleta de Dados (SBCD) are seen in :numref:`tab:telemetry-sbcd`.
